# Infinite Atelier Brand Spec

## Brand Assets

- Primary mark: `web/public/brand-logo.png`
- Source: owner-provided brand artwork
- Browser icon: `web/public/brand-logo.png`

The mark is used as an image or CSS mask. Do not redraw or replace it with a generic icon.

## Visual System

- Base: deep black and pearl-white editorial surfaces.
- Accent palettes: Garnet, Jade, Sapphire, Amethyst, and Pearl.
- Shape: compact 6-8px corners for controls; up to 16px for repeated project and prompt cards.
- Motion: layered brand-mark parallax, silk-light sweeps, orbit lines, and slow editorial marquees. Motion must be clearly visible while remaining calm and elegant.
- Reduced motion: all decorative movement must stop when `prefers-reduced-motion` is enabled.

## Home Page

- The first viewport is a working launch surface, not a marketing landing page.
- The Infinite Atelier mark is a layered kinetic centerpiece with restrained jewel-color registration effects.
- Primary actions create a canvas or open an existing creative tool.
- Prompt cards use artwork-first layouts and support copying, saving, custom cover uploads, and user-created prompt entries.
